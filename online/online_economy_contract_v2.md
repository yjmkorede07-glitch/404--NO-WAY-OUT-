# ONLINE ECONOMY / PROPERTY / WORLD CONTRACT — Phase 24

Online is a persistent-feeling shared world, not only a queue of missions.

## Server-authoritative systems
- cash and bank balances
- property ownership
- businesses and upgrades
- stock holdings
- vehicle ownership
- BlackNet orders
- construction contracts and progress
- weather/world event state where shared
- freemode activities

## Story parity
Story mode receives the same *system families* where appropriate: properties, vehicles, stock, businesses, construction and BlackNet. Story events can override or author market/world state for authored missions without changing Online's server economy.

## Anti-exploit rule
Clients request transactions. The server validates funds, ownership, inventory, cooldowns and progression before committing state.
