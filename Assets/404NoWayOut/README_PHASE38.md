# 404: NO WAY OUT — Phase 38

## Build
Phase 38 is the first executable core-gameplay layer in the Unity production path.

Use Unity Editor menu:
`404 > Build Phase 38 Gameplay Test Scene`

Then open:
`Assets/404NoWayOut/Scenes/404_Phase38_GameplayTest.unity`

Press Play.

## Test controls
- WASD: move
- Left Shift: sprint
- Mouse: camera
- 1/2/3: Darius/Malik/Amara
- T: talk
- F: enter/exit vehicle
- G: robbery
- H: detain
- J: arrest
- B: boat/aircraft boarding

There is intentionally no universal E interaction.

## Doors
Ordinary doors open automatically when an authorized player/vehicle approaches. Normal door traversal does not require a button.

## Production boundary
The test scene uses primitives. Replace them with final 3D characters, vehicles, environments, animations, materials, VFX, audio and cinematics without changing the gameplay contracts.
