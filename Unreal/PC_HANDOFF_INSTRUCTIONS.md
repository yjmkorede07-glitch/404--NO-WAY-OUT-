# When a Larger PC Becomes Available

1. Install Epic Games Launcher.
2. Install Unreal Engine 5.6.1.
3. Extract this package.
4. Open `Unreal/NoWayOut.uproject`.
5. Allow C++ compilation.
6. Press Play and verify the greybox.
7. Do not create a new project.
8. Keep this package as the working source until the first successful compile is confirmed.
9. After compile success, continue with the next phase package generated by the builder.

If compilation fails, send only the exact first compiler error (file, line, message) and a screenshot if useful.
