# Contribution Rules

1. Treat the repository as the single source of truth.
2. Do not delete or replace the cumulative project to start over.
3. Keep Unity-generated folders out of version control.
4. Do not commit secrets, API keys, credentials, or local `.env` files.
5. Keep production assets rights-cleared before shipping.
6. Validate JSON/C# structure before committing large changes.
7. Do not claim Unity runtime validation until it has been tested in the Unity Editor/build environment.
