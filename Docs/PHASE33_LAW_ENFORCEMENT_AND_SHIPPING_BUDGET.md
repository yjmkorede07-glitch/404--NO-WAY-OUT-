# Phase 33 — Law Enforcement Career + Shipping Budget

## Law enforcement player role
Accepted players who choose the Force become an actual playable law-enforcement role. NPC police remain active globally.

Core actions: plate checks, ID checks, vehicle stops, detain/arrest, citations, backup dispatch, ambulance requests, fire requests, tow/recovery, incident reports and scene perimeters.

Every action is server-authoritative and audited. Acceptance is still human/admin controlled. Rank controls permissions.

## Mobile target
The project now has a deliberate **3–5 GB mobile shipping target**, not a promise that every future asset will fit automatically. The build must enforce budgets throughout production.

Methods: streaming, LODs, texture compression, mesh simplification, selective audio, optional language packs, mobile-specific effects and removal of editor/source/intermediate data.

## PC/console target
The planning range is **40–100 GB shipped**, with ~65 GB as a working target. High-resolution asset packs may increase size, while optional packs can keep the base install smaller.

## How PC/console players get it
The game is architected for normal platform storefront distribution: downloadable PC/console package plus patchable content packs. Final storefront choice, certification and release setup happen during release production.

## Phase package size warning
Incremental phase ZIP sizes are NOT game size. A 17 KB Phase 32 package contains only the changes introduced in that phase. It is not a 17 KB copy of the whole game. The final install is determined by cooked/shipped assets, audio, maps, shaders, localization and platform packaging.
