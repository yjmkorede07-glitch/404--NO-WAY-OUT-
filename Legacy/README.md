# Legacy production phases

Phases 34 and 35 were completed before the Unity 6.3 LTS production lock and were not previously uploaded to the GitHub repository.

They are preserved here so the GitHub repository contains the complete historical source/contracts that informed the current production architecture.

- `Phase34/` — core gameplay interaction, world simulation, agents, law-enforcement career, and related Unreal/Godot contracts.
- `Phase35/` — prison/custody, fugitive rules, underground networks, maritime/aircraft/property contracts, character asset request, and production completion gate.

These folders are **legacy/reference material**, not the active Unity runtime. The active production source remains the Unity project under `Assets/`, `Packages/`, `ProjectSettings/`, and the engine-neutral contracts under `Portable/`.
